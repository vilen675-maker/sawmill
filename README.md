# Sawmill PWA — веб-версия для iPhone

Это самостоятельный PWA-прототип: калькулятор объёма бревна/досок, схематичная карта раскроя, чек-лист распиловки, локальные заказы и экспорт JSON.

## Опубликовать бесплатно через GitHub Pages (можно из Safari на iPhone)
1. В Safari открой https://github.com и создай аккаунт/выполни вход.
2. Нажми **+** → **New repository**. Назови `sawmill`, выбери **Public**, нажми **Create repository**.
3. На странице репозитория нажми **Add file** → **Upload files**.
4. Загрузи все файлы из этой папки (`index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`, `icon.svg`). Можно также загрузить README.
5. Нажми **Commit changes**.
6. Открой **Settings** → **Pages**. В **Build and deployment** выбери **Deploy from a branch**, branch `main`, folder `/ (root)`, затем **Save**.
7. Подожди, пока GitHub Pages опубликует страницу. Адрес будет вида `https://ТВОЙ-ЛОГИН.github.io/sawmill/`.
8. Открой адрес в Safari на iPhone → кнопка **Поделиться** → **На экран «Домой»** → включи **Открывать как веб-приложение**, если такой переключатель показан → **Добавить**.

## Офлайн и данные
Открой опубликованную страницу при подключённом интернете хотя бы один раз, дождись загрузки и перейди по вкладкам. Service Worker кеширует основные файлы; заказы и чек-лист сохраняются в локальном хранилище Safari на этом устройстве. Не очищай данные сайта, иначе локальные записи могут исчезнуть. Экспортируй заказы периодически как резервную копию.

## Ограничения прототипа
- Это веб-приложение, не нативный IPA.
- Раскрой визуализируется схематически и не является производственным оптимизатором.
- Калькулятор использует цилиндрическую оценку объёма и не учитывает кору, конусность, обзол, дефекты и точную геометрию пропилов.
- Поле пропила пока отображается в расчёте, но не моделирует реальную потерю древесины.
- Переключатель единиц пока информационный; калькулятор вводит значения в мм и м.
- GitHub Pages делает сайт публично доступным по ссылке. Не размещай там персональные или коммерчески чувствительные данные. Данные заказов в обычном режиме остаются в локальном браузере.
